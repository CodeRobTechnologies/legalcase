# LegalCase Documentation

LegalCase is a legal case management SaaS built with **FastAPI** (backend) and **React + Vite** (frontend).

## Documentation index

| Folder | Purpose |
|--------|---------|
| [dev/](dev/) | Local setup, project structure, scripts, and deployment |
| [feature/](feature/) | Product features, API areas, and user-facing capabilities |
| [required/](required/) | Prerequisites, dependencies, and environment variables |

## Quick start

```bash
# From the repository root
npm run dev          # macOS / Linux
npm run dev:windows  # Windows
```

- Frontend: http://127.0.0.1:5173
- API: http://127.0.0.1:5000
- API docs: http://127.0.0.1:5000/docs

See [dev/setup.md](dev/setup.md) for full setup instructions.
